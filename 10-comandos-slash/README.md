# 10 — Comandos Slash (`/`)

## Por que aparecem 100+ opções?
O menu junta:
- comandos nativos do Grok Build
- skills instaladas (`~\.claude\skills`, `~\.agents\skills`, bundled)
- workflows
- comandos personalizados

## Como não se perder
1. Digite `/` e **já filtre**: `/rev` → review
2. Memorize 8–12 do dia a dia
3. Use o **simulador** no portal (módulo 10)

## Top do dia a dia
| Comando | Quando |
|---|---|
| `/plan` | Tarefa grande |
| `/review` | Antes de commit |
| `/docs` | Dúvida de sintaxe |
| `/memoria` | Registrar aprendizado |
| `/novidades` | Radar semanal |
| `/learn` | Melhorar skills |
| `/create-skill` | Automatizar repetição |
| `/create-workflow` | Pipeline multiagente |
| `/always-approve` | Permissões da sessão |
| `/help` | Perdeu-se |

## Analogia
O `/` é o cardápio do restaurante inteiro. Você não lê as 120 páginas — pede “massa” e o garçom filtra.
