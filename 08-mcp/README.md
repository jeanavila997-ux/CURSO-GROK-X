# 08 — MCP (Model Context Protocol)

## O que é
Padrão para o agente plugar ferramentas externas (GitHub, Gmail, REA…).

## Analogia
MCP = tomada universal. Grok = aparelho. Servidor MCP = eletrodoméstico.

## Servidores na máquina do Jean
- github, gmail, google_drive, notion
- mestre_do_pc, rea, cursor, exa, tasks

## Como usar (mental model)
1. `search_tool` com palavra-chave
2. Ler o schema
3. `use_tool` com argumentos corretos

## Exercício
Peça: "use search_tool para achar ferramentas do GitHub e me ensine o schema".
