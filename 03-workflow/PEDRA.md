# Workflow PEDRA

## Ciclo
1. **P**edir — 1 frase de objetivo
2. **E**sboçar — `/plan` se for grande
3. **D**esenvolver — Grok edita e explica
4. **R**evisar — `/review`
5. **A**notar — Obsidian / InfoMaquina

## Exemplo bom
```
Crie um script pwsh que liste portas em 127.0.0.1
e explique cada linha no modo professor.
```

## Exemplo fraco
```
arruma meu pc
```

## Checklist de sessão
- [ ] Objetivo escrito
- [ ] Pasta/projeto certo (não ProjetosPessoais)
- [ ] AGENTS.md do projeto lido
- [ ] Verificação (teste/browser/curl)
- [ ] Anotação final
