# 02 — Estrutura do Curso

## Quatro trilhas
| Trilha | Foco |
|---|---|
| CLI | Grok Build no terminal |
| Bot | Grok no X e automações |
| MCP | Conectores externos |
| Ecossistema | Empresas Elon + ideias |

## Níveis
- **Iniciante:** pedir tarefas claras, usar `/help`, marcar progresso
- **Intermediário:** skills, MCP, plan mode
- **Avançado:** workflows, subagents, bots, integrações

## Como navegar
1. Portal (`index.html` via `iniciar-curso.cmd`)
2. Pastas numeradas com README de cada módulo
3. Anotações no próprio portal (salvas no navegador)

## Analogia
Trilha = corredor da escola. Nível = série. Portal = mural de avisos.
